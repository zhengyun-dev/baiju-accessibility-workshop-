# 演示视频 · 分镜表（3–5 分钟，照着录）

> 对着 `ui/index.html`（浏览器全屏）+ 终端 录屏。
> 全程不要出现任何 API key / 密码（公告第5条）。
> 每段单独剪一个镜头，别一镜到底，方便后期。

## 准备（录前 2 分钟）

1. 起服务：
   ```
   cd /home/yunnn/baiju-accessibility/ui
   python3 -m http.server 8080
   ```
2. 浏览器全屏打开 `http://localhost:8080`，选「远山黛水」配色（最稳）
3. 终端窗口打开，`cd /home/yunnn/baiju-accessibility/sources/02_clean/skill_trace`
4. 录屏软件：**固定窗口模式**（分别录"浏览器窗""终端窗"），别录整桌

---

## 镜头 1 · 痛点（0:00–0:35）浏览器全屏

**画面**：白屏出标题「白局 · 有声金陵」，切到一段无翻译的白局唱词纯文字。
**口播**：
> 南京白局是国家级非遗曲艺，用南京话唱。听障者听不见，游客和年轻人听不懂——唱词的内容，对他们是不存在的。
> 我们的作品，把一段白局唱词，变成听得懂、查得到、信得过的无障碍内容。

## 镜头 2 · 全链路（0:35–1:50）浏览器全屏 ★

**画面**：点预设「机房苦」→ 点「一键全链路」，网页依次亮起 01→05。
**口播**：
> 五个能力：01 逐句切开、标出南京方言词；02 逐句翻成白话，拿不准的标存疑、不硬译；03 从南京典故知识库匹配，做带来源的知识卡；04 逐张核验来源 URL、算溯源率；05 对比原文和白话的难词率，量化好懂了多少。
> 01、04、05 是确定性计算，浏览器直接跑；02、03 交给 Agnes 模型生成。

## 镜头 3 · 指标（1:50–2:40）浏览器全屏

**画面**：停在 05 报告，放大两个数字。
**口播**：
> 两个硬指标：机房苦难词率从 2.9% 降到 0%，降了一百零一——不是，降了一百。知识卡溯源率百分之百，每张卡都能点出来源。合规上，所有素材带公开来源，拿不准的含义一律标待考，不编造。

## 镜头 4 · AGH 证据（2:40–3:40）终端 ★★ 答辩重点

**画面**：终端 `cat skill_trace_2_translate.txt`，滚动到 `- tool skill_read · ok` 和 `translator` 字段。
**口播**：
> 核心任务不是人写的，是 Agnes 模型在 AGH 里真实执行的。这是 AGH 执行记录：skill_read 说明 AGH 激活了 Skill；输出里 translator 等于 agnes-3.0-flash，是模型生成的；知识卡那条还读了知识库文件再匹配，不是凭记忆编。
> 三个确定性工具构成工具调用链，全程可复现、不依赖模型。

## 镜头 5 · 收尾（3:40–4:20）浏览器全屏

**画面**：回网页全貌，定格标题 + 双指标。
**口播**：
> 一句话：用 AGH 把一段非遗唱词，变成听障者和年轻人看得懂、查得到、信得过的内容。代码、词表、知识库、AGH 执行记录全部开源在赛事仓库。谢谢。

## 录制注意

- **每段切一个镜头**，后期再剪接（别 5 分钟一镜到底，出错就全废）
- ⑤ 口播那句「一百零一——不是，一百」**别真这么念**，念「降了一百」就行（写口误是提醒你别卡壳）
- 全程屏幕**不要出现**任何 key、token、密码
- 录完丢进 `demo_video/`，命名 `demo.mp4`（≤3–5 分钟，压到 3 分半最稳）
- 视频文件别太大（≤200MB 是整个 ZIP 上限，视频占大头）——1080p 就够，720p 更省
