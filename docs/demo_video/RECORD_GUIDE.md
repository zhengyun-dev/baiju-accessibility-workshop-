# 录屏速查表（A4 一屏，打印或贴屏幕边）

> 目标：5 个镜头各录一段（每段 30–60s），后期剪成 3–4 分钟。
> 工具：Windows 自带 **Win + G**（Xbox Game Bar），不用装软件。

## 开录前（5 分钟）

```
# WSL 里起网页（新开一个终端）
cd /home/yunnn/baiju-accessibility-workshop/web/web-ui
python3 -m http.server 8080
# 浏览器开 http://localhost:8080，按 F11 全屏

# 另开一个终端（镜头4用）
cd /home/yunnn/baiju-accessibility-workshop/data/02_clean/skill_trace
```

**安全**：起服务前确认终端里**没有** `export AGNES_API_KEY=...` 这种明字（镜头4录的是 skill_trace 目录，本身干净，但保险起见清屏 `clear` 一下）。

## 5 个镜头（照念 + 照做）

### 镜头 1 · 痛点（~35s） 浏览器全屏
**做**：白屏出标题「白局 · 有声金陵」→ 切一段无翻译的白局唱词纯文字。
**念**（口语版，标了停顿 /）：
> 南京白局 / 是国家级非遗曲艺 / 用南京话唱。
> 但问题是——听障者听不见 / 外地游客和年轻人 / 听不懂南京话。
> 也就是说 / 唱词的**内容** / 对他们**是不存在的**。
> 我们的作品 / 就是把一段白局唱词 / 变成**看得懂、查得到、信得过**的无障碍包。

### 镜头 2 · 全链路（~75s） 浏览器全屏 ★
**做**：点预设「机房苦」→ 点「一键全链路」→ 看 ①→⑤ 依次亮起。
**念**：
> 整条链路 / 五个能力。我带大家看一遍——
> **01 分析唱词** / 逐句切开 / 标出南京方言词；
> **02 白话翻译** / 逐句翻成普通话 / 拿不准的**标"存疑"、不硬译**；
> **03 知识卡** / 从我们的南京典故知识库匹配 / 每张卡带来源；
> **04 来源核验** / 逐张核验来源 URL / 算**溯源率**；
> **05 可读性报告** / 对比原文和白话的难词率 / 量化到底好懂了多少。
> 其中 / 01、04、05 是确定性计算 / 浏览器直接跑；
> 02、03 交给 **Agnes 模型**生成。

### 镜头 3 · 指标（~50s） 浏览器全屏
**做**：停在 ⑤ 报告 / 放大两个数字（4.6%→0% 和 溯源率 100%）。
**念**：
> 两个硬指标——
> 《机房苦》**难词率从 4.6% 降到 0%** / 降了一百；
> 知识卡**溯源率 100%** / 每张卡都能点出来源 URL。
> 合规上 / 所有素材都带公开来源 / 拿不准的词**一律标"待考"、不编造**。

### 镜头 4 · AGH 证据（~60s） 终端 ★★ 答辩重点
**做**：终端里 `cat skill_trace_2_translate.txt` / 滚到三处：`skill_read`、`translator = agnes-3.0-flash`、`（存疑：坐板疮）`。
**念**：
> 这是评审最看重的证据 / 核心任务**不是人写的** / 是 Agnes 模型在 AGH 里**真实执行的**。
> 这份是 AGH 执行记录——
> 第一行 `skill_read` / 说明 AGH **激活了 Skill** / 不是模型背答案；
> 输出里 `translator = agnes-3.0-flash` / 说明白话是**模型生成的**；
> 你看这里 / `存疑：坐板疮` / 拿不准的词**不硬译、标存疑**。
> 三个确定性工具 01、04、05 构成工具调用链 / 全程可复现 / 不依赖模型。

### 镜头 5 · 收尾（~30s） 浏览器全屏
**做**：回网页全貌 / 定格标题 + 双指标。
**念**：
> 一句话——用 AGH / 把一段非遗唱词 / 变成听障者和年轻人**看得懂、查得到、信得过**的内容。
> 代码、词表、知识库、AGH 执行记录 / 全部开源在赛事仓库。
> 谢谢。

## Win+G 怎么按
1. `Win + G` 调出 Game Bar → 点相机图标 **开始录制**
2. 做镜头 1 的操作 + 念完 → `Win + G` 点相机 **停止**（存到 视频库/录屏）
3. 换镜头 2 / 3 / 4 / 5 / 重复。**每段单独录** / 录错只重录那段。
4. 默认存到 `C:\Users\<你>\Videos\Captures` / 复制出来重命名 `demo1.mp4` ... `demo5.mp4`。
