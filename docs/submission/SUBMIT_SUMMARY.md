# 提交说明（供赛事系统表单 / 客服沟通用）

## 作品名称
白局·有声金陵 —— 南京白局无障碍唱词工坊

## 一句话摘要
用 Agnes Harness (AGH) 的 5 个能力（3 个确定性 Tool + 2 个模型 Skill），把濒危非遗「南京白局」的南京方言唱词，转成听障者与方言不熟者也能读懂的"无障碍包"——白话翻译 + 带 URL 的典故知识卡 + 可读性量化报告，双硬指标达标（知识卡溯源率 100%、白话版难词率下降 100%），全程合规（素材带来源、拿不准标"待考"不编造、不含任何 Key/密码）。

## 五个能力
| 编号 | 名称 | 类型 | 作用 |
|---|---|---|---|
| ① | parse_text | Tool | 逐句切开唱词、标出南京方言词 |
| ② | translate-to-plain | Skill | 逐句翻成普通话白话，拿不准标"存疑"不硬译 |
| ③ | gen-knowledge-cards | Skill | 从南京典故知识库匹配、生成带来源的知识卡 |
| ④ | verify_sources | Tool | 逐张核验来源 URL、算溯源率 |
| ⑤ | readability_score | Tool | 对比原文/白话难词率、量化"好懂了多少" |

## 双硬指标（已验证）
- 知识卡溯源率：**100%**（每张卡都能点出来源 URL）
- 白话版难词率下降：**4.6% → 0%（下降 100%）**
- 三类测试样例（normal / boundary / failed）：**全部通过**
- 存疑标注：**100% 覆盖**
