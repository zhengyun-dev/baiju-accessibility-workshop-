# 作品详情（≤5000 字）

## 一、作品名称
白局·有声金陵 —— 南京白局无障碍唱词工坊

## 二、一句话概述
用 Agnes Harness (AGH) 的 5 个能力（3 个确定性 Tool + 2 个模型 Skill），把濒危国家级非遗「南京白局」的南京方言唱词，转成听障者、外地游客与方言不熟者也能读懂的「无障碍包」——白话翻译 + 带来源 URL 的典故知识卡 + 可读性量化报告，双硬指标达标，全程合规。

## 三、解决什么问题
南京白局是国家级非物质文化遗产曲艺，用南京话演唱。但它的唱词对三类人几乎是「不存在」的内容：
- **听障者**：听不见唱腔，也看不懂无字幕的唱词；
- **外地游客 / 非南京籍观众**：不懂南京方言，听不出「坐板疮」「腰子箩」在说什么；
- **年轻一代**：方言正在流失，白局唱词里的典故（夫子庙、秦淮、朱雀桥、乌衣巷）缺乏「看得懂」的入口。

博物馆有云锦、秦淮灯的解说词，却唯独缺白局唱词的「看得懂」版本。本作品做的事，就是给白局唱词补上这一环：把一段唱词，变成**看得懂（白话翻译）、查得到（可溯源知识卡）、信得过（可读性量化 + 合规标注）**的无障碍内容。

## 四、作品构成：5 个能力（3 Tool + 2 Skill）
整条链路 5 个能力，分工明确——**确定性计算交给 Tool，内容生成交给 Agnes 模型（Skill）**：

| 编号 | 能力 | 类型 | 作用 |
|---|---|---|---|
| ① | parse_text | Tool | 把唱词逐句切开，标出其中的南京方言词（用 361 词方言词表子串匹配，不依赖分词） |
| ② | translate-to-plain | Skill | 逐句翻成普通话白话；**拿不准的方言词标「存疑」、不硬译**（Agnes 模型生成） |
| ③ | gen-knowledge-cards | Skill | 从南京典故知识库匹配典故，生成**每张都带来源 URL** 的知识卡；无命中返回 miss、不编造（Agnes 模型生成） |
| ④ | verify_sources | Tool | 逐张核验知识卡的来源 URL，算出**溯源率** |
| ⑤ | readability_score | Tool | 对比原文与白话版的「难词率」，量化「到底好懂了多少」 |

**为什么这样分**：①④⑤ 是确定性计算，浏览器/本地直接跑，结果稳定可复现、不依赖模型；②③ 是「内容生成」，交给 Agnes 模型——这是评审最看重的证据：**核心任务不是人写的，是 Agnes 在 AGH 里真实执行的**（有 AGH 执行记录为证）。

## 五、核心证据：Agnes 真实参与
`data/02_clean/skill_trace/` 保存了两份 AGH 执行记录（终端 trace）：
- ② 的 trace 第一行 `- tool skill_read · ok`，说明 AGH 真正**激活了 Skill**，不是模型凭记忆硬答；输出里每句都带 `"translator": "agnes-3.0-flash"`，说明白话是**模型逐句生成的**；其中 `（存疑：坐板疮）（存疑：焦头鸡）` 证明「不硬译、标存疑」的合规规则被**模型本身执行**，不是事后补的。
- ③ 的 trace 有 `- tool skill_read` + `- tool read`，说明模型**真读了知识库文件 `nanjing_landmarks.md` 再匹配**，无命中项返回 miss、不编造。

## 六、双硬指标（已实测）
- **知识卡溯源率：100%**（每张卡都能点出来源 URL，无一凭空）
- **白话版难词率下降：100%**（《机房苦》原文 4.6% → 白话版 0%，下降 100%）

## 七、三类测试样例（全通过）
| 类型 | 输入 | 结果 |
|---|---|---|
| normal | 正常唱词《机房苦》 | 全链路正常，难词率 4.6%→0%（降 100%） |
| boundary | 歇后语谐音双关「草帽么得边儿——顶好」 | 「顶好」进 harmony（谐音双关**不计入难词**），「么得」按方言词计入，边界正确 |
| failed | ③ 查不到「不存在的典故」+ ④ 无来源卡 | 「不存在的典故」traceable=no、**降级「待考」**、不崩溃；有来源的卡仍 traceable=yes |

## 八、合规（规则 3.4）
- **每个素材都标注来源 URL**（唱词、词表、知识库、背景资料共 18 项登记于 `sources_manifest.csv`）；
- **只引用/改写，不商用分发**；
- **拿不准的词义一律标「待考」，绝不编造**（知识卡里的「莫愁湖地理典故」「雉头鸡/惛头鸡」等已如实标「待考/待补来源」）；
- **粗俗词单列**（31 个），不计入难词率；
- **歇后语谐音双关词（针好/顶好）单独进 harmony**，不误判为难词；
- **提交材料经 grep 检查，无任何明文 API Key / 密码 / PAT**（需 Key 处均为环境变量占位）。

## 九、数据集与知识资产
- 唱词：6 段（c01–c06，逐句清洗对齐）；
- 背景资料：9 份（k01–k09，含白局非遗、南京地标等）；
- **361 词南京方言词表**（三层：361 难词 / 2 歇后语谐音 / 35 文化专名），外部化为 `dialect_words.json`；
- 南京典故知识库 `nanjing_landmarks.md`（10 张地标卡：夫子庙、秦淮、朱雀桥、乌衣巷、白鹭洲、媚香楼等）。
