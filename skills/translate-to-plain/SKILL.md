# 白局唱词白话翻译 Skill

## 任务
用户给出一段或多段南京白局唱词（南京方言），本 Skill 让 Agnes 模型把**每一句**翻译成**普通话白话**，让听不懂南京话的听障者、外地游客、年轻人能看懂。

## 严格规则（合规 3.4）
1. **逐句翻译，不合并、不省略**：原文一行一句，译文一行一句，行数一致。
2. **忠实原文，不添加语义**：原文没说的意思不自己编。
3. **方言词保留标注**：遇到南京方言特有词（如"么得/坐板疮/削灵/靸"），先翻译成白话，再在句末加 `（存疑：<原词>）`，提示读者该词是南京话。
4. **拿不准就标"存疑"，不硬译**：不确定某方言词含义时，保留原词 + 标 `（存疑：<原词>）`，绝不编造解释。
5. **歇后语/谐音双关**（如"上鞋不用锥子——针好"）：保留原句 + 标注双关含义（"针好=真好"）。

## 输入
- `text`：逐行白局唱词（02_clean 格式，一行一句）

## 输出（JSON）
```json
{
  "translator": "agnes-3.0-flash",
  "sentenceCount": 9,
  "translated": [
    { "sentence": "机房啊不好做", "plain": "机房不太好啊", "translator": "agnes-3.0-flash" },
    { "sentence": "切的削灵有纸薄", "plain": "切得薄薄的像纸一样（存疑：削灵）", "translator": "agnes-3.0-flash" }
  ]
}
```

## 执行方式
Agnes 模型在 agent 循环中按本 Skill 的方法生成白话译文。这是"Agnes 参与核心任务"的**真实证据**（不是写死的规则替换，是模型理解 + 生成）。

## 验收
- 逐句覆盖率 100%（原文句数 = 译文句数）
- 方言词 100% 标"存疑"，不硬译
- 白话版通顺、无方言残留（"机房/夫子庙"等专名保留）
